# Pogo downloads

Official signed Pogo installers. This repository contains distribution information and release assets only.

## Mac prerelease

[Download Pogo 0.1.8 for Apple silicon](https://github.com/saberra-ai/pogo-downloads/releases/download/v0.1.8/Pogo_0.1.8_aarch64.dmg)

Requires macOS 12 or newer and an Apple silicon Mac. The app and installer are Developer ID signed and notarized by Apple.

**Activation is currently paused.** This prerelease build connects to the Pogo licensing service, where new activation and purchases are disabled. Download availability does not mean paid activation is available.
